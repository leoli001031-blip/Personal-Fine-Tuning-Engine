# PFE Phase2 展示网页素材

这个目录是一份可直接打开的展示网页素材包。

- `index.html`：静态展示页入口。
- `styles.css`：暖米咖工作台视觉样式。
- `showcase-preview.png`：展示页首屏预览图。
- `assets/studio-workbench.png`：主视觉截图。
- `assets/base-local-proof.png`：base/local 效果对比图。
- `assets/eval-gate.png`、`assets/promoted-adapter.png`、`assets/api-handoff.png`：闭环过程截图。
- `materials.json`：网页素材和证据清单。

素材来自 `docs/demo/showcase/screenshots/` 和 `docs/demo/showcase/evidence/`，不包含 `videos/`。
